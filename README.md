# 🏀 SubTracker PWA — Basketball & Sports Rotation Manager

A fast, zero-dependency Progressive Web App (PWA) designed for basketball and team sports coaches to track player rotations, fair-play minutes, live shifts, and substitutions right on the sideline.

### 🌐 Live App
👉 **[https://nickpstone.github.io/subtracker-pwa/](https://nickpstone.github.io/subtracker-pwa/)**

---

## ⚡ Core Features
- **Master Period & Match Timers**: Configurable quarter/half lengths, automatic period expiration buzzer/whistle, and continuous total game elapsed timer.
- **Fair Play Rotation Assistant**: Automatically suggests subbing off the player running the longest continuous shift for the most well-rested bench player.
- **Live Stint Trackers**: Real-time continuous stint timers showing how long a player has been running on court (`⚡ Shift: MM:SS`) or resting on the bench (`🌙 Rest: MM:SS`).
- **1-Tap Substitutions**: Big high-contrast `START` and `STOP` controls, plus a Quick 1-to-1 Swap drawer.
- **Audit Log & Analytics**: Chronological sub timeline, player percentage bar charts, 1-tap summary sharing, and CSV data export.
- **100% Offline Capability**: Built-in Service Worker ensures smooth performance in gyms or arenas with zero cellular reception.
- **Screen Wake Lock**: Automatically keeps your mobile screen awake during live matches so coaches never need to unlock mid-game.
- **State Persistence**: Match state and rosters are saved automatically to `localStorage` so refreshing or switching tabs never loses game progress.

## 📱 How to Install as an App (PWA)

### iPhone / iPad (Safari)
1. Open [https://nickpstone.github.io/subtracker-pwa/](https://nickpstone.github.io/subtracker-pwa/) in Safari.
2. Tap the **Share** button (box with upward arrow).
3. Scroll down and tap **Add to Home Screen**.
4. Tap **Add**. SubTracker will appear as a native full-screen app on your home screen.

### Android / Chrome
1. Open [https://nickpstone.github.io/subtracker-pwa/](https://nickpstone.github.io/subtracker-pwa/) in Chrome.
2. Tap the **Install** prompt in the address bar or the three-dots menu -> **Install app**.
